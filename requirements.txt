# LUC-Robot - every runtime dependency of every stage, in one file.
#
# This is the "install it all at once" path, for a fresh clone or the kiosk device:
#
#     pip install -r requirements.txt
#
# The per-stage files (stages/stageNN_.../requirements.txt) are still the source of truth for
# WHY each pin exists - each one carries the licensing note, the wheel-availability reason, or
# the version-conflict history behind its choice. Read those before changing a number here.
# They also remain the incremental path: while building stage by stage you install only the
# stage you've reached, and you don't pull ~2GB of torch on day one just to run stage00's
# hardware check.
#
# Keep the two in sync: a pin added to a stage file belongs here too.
#
# READ FIRST - two things this file cannot express on its own:
#
#   1. opencv. Stage 00 pins opencv-python and Stage 02 needs opencv-contrib-python, which is a
#      strict SUPERSET of it. Installing both into one environment makes them fight over the
#      same files, so only the contrib build is listed below. ultralytics (Stage 01) declares
#      opencv-python as its own dependency and pip will therefore pull it back in anyway - see
#      INSTALL.md, "The opencv wrinkle", for the one uninstall that cleans that up and why the
#      `pip check` warning it leaves behind is harmless.
#
#   2. Three things are not pip packages at all and are NOT installed by this file:
#        - Ollama          (the local fallback LLM - see INSTALL.md step 6)
#        - MySQL           (persistent memory for faces + transcripts - INSTALL.md step 5)
#        - model weights   (YOLOv8n, YuNet, SFace, Piper voice, Whisper - INSTALL.md step 4).
#          They're gitignored on purpose: ~170MB of binaries that each have a one-line
#          re-download command.

# torch comes from PyTorch's CPU wheel index rather than PyPI, so a laptop without a matching
# NVIDIA driver setup doesn't silently pull a multi-gigabyte CUDA build. On a real Jetson,
# torch needs NVIDIA's own Jetson-specific build instead and this pin does not apply - install
# everything else from this file with `--no-deps` for torch, or drop the torch line there.
--extra-index-url https://download.pytorch.org/whl/cpu
